# NOVA SALVAGE

An original 2D canvas arcade game for make.fun best-game-01.

NOVA SALVAGE is an original top-down 2D canvas arcade game where you pilot a salvage tug through an asteroid belt, blast rocks, collect 24 star-cores, chain combos and clear 8 waves to break the Derelict Hulk.

## How to play

- **Controls**: WASD / Arrow keys to move, mouse to aim, hold left-click to fire, Space to dash, P to pause, M to mute, Enter to start, R to restart.
- **Rules**: Start with 100 hull points. Rocks split into smaller debris when destroyed. Collect star-cores to increase your score multiplier and achieve high combos. Collect all 24 cores for a full salvage bonus (+5000 points). Survive through wave 8 to face and clear the Derelict Hulk to win the game.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
open game/index.html in desktop Chrome (or serve game/ with any static server)
```
